# HU-08: Integración con wearables (OAuth web)

> **Sprints:** 9-10 · **Etiqueta:** 🏗️ Cimiento · **Esfuerzo:** 20 días-persona · **Branch:** `feat/HU-08-wearables-oauth`

---

## Objetivo
Permitir conectar wearables vía OAuth web (Fitbit, Garmin, Oura) para importar pasos, calorías quemadas, peso, sueño y HRV. Influir en recomendaciones nutricionales del coaching (HU-09).

---

## Decisiones aplicadas
- **D2:** **OAuth web únicamente**. Sin Capacitor/React Native. Sin Apple HealthKit ni Google Health Connect.
- Orden de implementación: **Fitbit → Oura → Garmin** (de más fácil a más complejo)

---

## Estado previo (FALTA)
- Sin OAuth de terceros (solo NextAuth para login propio)
- Sin modelo de actividad
- Sin sincronización background

---

## Arquitectura

```
Usuario → /settings/wearables → click "Conectar Fitbit"
                                       ↓
                                  Redirect a Fitbit OAuth
                                       ↓
                                  Callback /api/wearables/callback/fitbit
                                       ↓
                                  Guardar tokens en WearableConnection
                                       ↓
                                  Sync inicial: últimos 7 días
                                       ↓
Vercel Cron diario: /api/cron/wearables-sync
                                       ↓
                                  Refresh token + fetch nuevos datos
                                       ↓
                                  Upsert ActivityData
```

## Encriptación de tokens

### `lib/crypto.ts`

```ts
import crypto from "crypto";

const ALGO = "aes-256-gcm";
const KEY = Buffer.from(process.env.WEARABLE_ENCRYPTION_KEY!, "hex"); // 32 bytes

export function encrypt(plaintext: string): string {
  const iv = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv(ALGO, KEY, iv);
  const ciphertext = Buffer.concat([cipher.update(plaintext, "utf8"), cipher.final()]);
  const tag = cipher.getAuthTag();
  return [iv.toString("hex"), tag.toString("hex"), ciphertext.toString("hex")].join(":");
}

export function decrypt(encrypted: string): string {
  const [ivHex, tagHex, ciphertextHex] = encrypted.split(":");
  const decipher = crypto.createDecipheriv(ALGO, KEY, Buffer.from(ivHex, "hex"));
  decipher.setAuthTag(Buffer.from(tagHex, "hex"));
  const plaintext = Buffer.concat([
    decipher.update(Buffer.from(ciphertextHex, "hex")),
    decipher.final(),
  ]);
  return plaintext.toString("utf8");
}
```

```ts
const FITBIT_AUTH = "https://www.fitbit.com/oauth2/authorize";
const FITBIT_TOKEN = "https://api.fitbit.com/oauth2/token";
const FITBIT_API = "https://api.fitbit.com";

const SCOPES = ["activity", "heartrate", "sleep", "weight"];

export function getAuthUrl(state: string): string {
  const params = new URLSearchParams({
    response_type: "code",
    client_id: process.env.FITBIT_CLIENT_ID!,
    scope: SCOPES.join(" "),
    redirect_uri: `${process.env.NEXTAUTH_URL}/api/wearables/callback/fitbit`,
    state,
  });
  return `${FITBIT_AUTH}?${params}`;
}

export async function exchangeCode(code: string) {
  const credentials = Buffer.from(`${process.env.FITBIT_CLIENT_ID}:${process.env.FITBIT_CLIENT_SECRET}`).toString("base64");
  const res = await fetch(FITBIT_TOKEN, {
    method: "POST",
    headers: {
      Authorization: `Basic ${credentials}`,
      "Content-Type": "application/x-www-form-urlencoded",
    },
    body: new URLSearchParams({
      grant_type: "authorization_code",
      code,
      redirect_uri: `${process.env.NEXTAUTH_URL}/api/wearables/callback/fitbit`,
    }),
  });
  if (!res.ok) throw new Error(`Fitbit token exchange failed: ${res.status}`);
  return res.json() as Promise<{ access_token: string; refresh_token: string; expires_in: number; user_id: string }>;
}
```

## Endpoints

### `GET /api/wearables/connect/fitbit`
1. Genera `state` único (CSRF)
2. Guarda `state` en cookie firmada con TTL 10 min
3. Redirige a `getAuthUrl(state)`

### `GET /api/wearables/callback/fitbit?code=...&state=...`
1. Verifica `state` contra cookie
2. `exchangeCode(code)` → tokens
3. Encripta y guarda en `WearableConnection`
4. Dispara sync inicial (últimos 7 días en background)
5. Redirige a `/settings/wearables?connected=fitbit`

### `DELETE /api/wearables/disconnect/fitbit`
1. Borra `WearableConnection`
2. Revoca el token vía API Fitbit (`POST /oauth2/revoke`)
3. Mantiene `ActivityData` (datos históricos quedan)

### Cron `GET /api/cron/wearables-sync` (4am UTC diario)
```ts
// Pseudocódigo

  if (conn.expiresAt < new Date()) {
    await refreshTokens(conn);

  await syncProvider(conn);
```

## Orquestador `lib/wearables/sync.ts`

```ts
export async function syncFitbitForUser(connection: WearableConnection) {
  const accessToken = decrypt(connection.accessToken);
  const today = new Date().toISOString().split("T")[0];
  const yesterday = new Date(Date.now() - 86400000).toISOString().split("T")[0];

  for (const date of [yesterday, today]) {
    const [activity, sleep] = await Promise.all([
      fetchActivities(accessToken, date).catch(() => null),
      fetchSleep(accessToken, date).catch(() => null),
    ]);
    if (!activity && !sleep) continue;

    await prisma.activityData.upsert({
      where: { userId_date_provider: { userId: connection.userId, date, provider: "fitbit" } },
      create: {
        userId: connection.userId,
        date,
        provider: "fitbit",
        steps: activity?.summary?.steps,
        caloriesBurned: activity?.summary?.caloriesOut,
        activeMinutes: activity?.summary?.activeMinutes,
        distanceKm: activity?.summary?.distances?.[0]?.distance,
        sleepMinutes: sleep?.summary?.totalMinutesAsleep,
        sleepEfficiency: sleep?.sleep?.[0]?.efficiency ? sleep.sleep[0].efficiency / 100 : null,
        rawJson: JSON.stringify({ activity, sleep }),
      },
      update: { /* mismos campos */ },
    });

    // Importar peso si existe (idempotente con manual: manual gana)
    if (activity?.weight?.length > 0) {
      for (const w of activity.weight) {
        await prisma.weightEntry.upsert({
          where: { userId_date: { userId: connection.userId, date: w.date } },
          create: { userId: connection.userId, date: w.date, weightKg: w.weight, source: "wearable" },
          update: {
            // Solo actualizar si no es manual
            ...((await prisma.weightEntry.findUnique({ where: { userId_date: { userId: connection.userId, date: w.date } } }))?.source !== "manual"
              ? { weightKg: w.weight, source: "wearable" }
              : {}),
          },
        });
      }
    }
  }

  await prisma.wearableConnection.update({
    where: { id: connection.id },
    data: { lastSyncedAt: new Date() },
  });
}
```

## Riesgos específicos

| Riesgo | Mitigación |
|---|---|
| Garmin requiere aprobación developer (Connect IQ Program) | Empezar por Fitbit/Oura; Garmin último |
| Rate limits diferentes por proveedor | Documentar en lib/wearables/*.ts; backoff en sync |
| Tokens pueden ser revocados por el usuario externamente | Manejar 401 en sync; marcar conexión como expired y notificar |
| Datos duplicados entre wearables (usuario con 2) | UNIQUE constraint (userId, date, provider); priorizar el más reciente |
| Encryption key perdida = todos los tokens inservibles | Backup seguro de WEARABLE_ENCRYPTION_KEY; rotación documentada |
| Apple Health requiere wrapper nativo | Documentar; abrir como future work |
| Vercel cron timeout 60s con muchos usuarios | Paginar; procesar batches de 50 |
