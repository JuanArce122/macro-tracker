# HU-11: Modo "sin tracking" / hábitos

> **Sprint:** 7 · **Etiqueta:** ⚡ Quick Win · **Esfuerzo:** 10 días-persona · **Branch:** `feat/HU-11-habits-mode`

---

## Objetivo
Ofrecer un modo alternativo de tracking basado en porciones visuales (proteína / vegetal / carbo / grasa) en lugar de números exactos, con detección suave de patrones obsesivos.

---

## Decisiones aplicadas
- **D7:** Umbrales TCA recomendados:
  - **Aviso suave:** >12 registros/día durante 3+ días
  - **Aviso suave:** >5 ediciones de la misma comida en un día
  - **Aviso fuerte:** racha 14+ días con goal cumplido exacto al 100% (±2 kcal)
  - Recurso profesional: línea ACAB Colombia + recursos en español

---

## Definición de "porción visual"

Mapeo aproximado:
- **1 porción de proteína** ≈ 25g proteína (palma de la mano) ≈ ~150 kcal
- **1 porción de verdura** ≈ 80g (puño) ≈ ~30 kcal
- **1 porción de carbo** ≈ 50g (puño cerrado) ≈ ~180 kcal
- **1 porción de grasa** ≈ 15g (pulgar) ≈ ~135 kcal
- **1 porción de fruta** ≈ 100g (puño) ≈ ~60 kcal

Default goals según `User.fitnessGoal`:
- **lose**: 4P · 5V · 3C · 2F · 2Fr/día
- **maintain**: 5P · 5V · 4C · 3F · 3Fr/día
- **gain**: 6P · 5V · 5C · 3F · 3Fr/día

## Detección suave de patrones (`lib/tca-detection.ts`)

```ts
/**
 * Heurísticas con tono empático para sugerir modo hábitos o recursos profesionales.
 * NUNCA diagnostica TCA.
 * Solo aviso suave; el usuario puede descartar.
 */

type Signal = "high_frequency" | "obsessive_editing" | "perfect_tracking" | null;

export async function detectConcerningPatterns(userId: number): Promise<Signal> {
  // Señal 1: >12 registros/día por 3+ días en última semana
  const sevenAgo = new Date(); sevenAgo.setDate(sevenAgo.getDate() - 7);
  const meals = await prisma.meal.findMany({
    where: { userId, createdAt: { gte: sevenAgo } },
    select: { dateLocal: true, createdAt: true },
  });
  const byDay = new Map<string, number>();
  meals.forEach((m) => byDay.set(m.dateLocal ?? "", (byDay.get(m.dateLocal ?? "") ?? 0) + 1));
  const daysWithExcess = Array.from(byDay.values()).filter((c) => c > 12).length;
  if (daysWithExcess >= 3) return "high_frequency";

  // Señal 2: >5 ediciones en una misma comida en un día (usando updatedAt vs createdAt)
  // (Requiere persistir histórico de edits — simplificación: contar PATCH /api/meals/[id])
  // Por simplicidad, omitimos esta señal en MVP y la dejamos como TODO

  // Señal 3: 14 días seguidos con calorías = goal ± 2 kcal (tracking obsesivo)
  const fourteenAgo = new Date(); fourteenAgo.setDate(fourteenAgo.getDate() - 14);
  const goal = await prisma.goal.findFirst({ where: { userId } });
  if (goal) {
    const dailyTotals = new Map<string, number>();
    const recent = await prisma.meal.findMany({
      where: { userId, date: { gte: fourteenAgo } },
      select: { dateLocal: true, calories: true },
    });
    recent.forEach((m) => {
      dailyTotals.set(m.dateLocal ?? "", (dailyTotals.get(m.dateLocal ?? "") ?? 0) + m.calories);
    });
    const perfectDays = Array.from(dailyTotals.values()).filter((c) => Math.abs(c - goal.calories) <= 2).length;
    if (perfectDays >= 14) return "perfect_tracking";
  }

  return null;
}
```

## Riesgos específicos

| Riesgo | Mitigación |
|---|---|
| Falsos positivos pueden estigmatizar usuarios sanos | Tono empático; siempre con opción "descartar"; nunca diagnostica |
| Cambio frecuente de modo confunde | Animaciones suaves; mensaje claro "puedes volver cuando quieras" |
| Recursos CO desactualizados | Verificar línea ACAB Colombia antes de release |
| Modo hábitos puede subestimar/sobreestimar calorías reales | Aclarar que es aproximación; no usar para metas estrictas |
| Detección obsesiva puede ofender | Mensaje opcional dismisable; revisar con experto antes de merge |
