## Endpoints nuevos

### `GET /api/export/json?from=&to=`
**Response:**
```json
{
  "exportedAt": "2026-05-22T10:00:00Z",
  "user": { "email": "...", "name": "...", "createdAt": "...", "countryCode": "CO" },
  "profile": { "age": 30, "weightKg": 70, "heightCm": 175, "activityLevel": "moderate", "fitnessGoal": "lose" },
  "goals": { "calories": 2000, "protein": 150, "carbs": 200, "fat": 65 },
  "meals": [
    { "id": 1, "date": "2026-05-20", "category": "breakfast", "name": "...", "weightG": 200, "calories": 350, "protein": 25, "carbs": 40, "fat": 8, "confidence": 0.92, "items": [...] }
  ],
  "customFoods": [ ... ],
  "totalDays": 45,
  "totalMeals": 230
}
```

**Headers:**
```
Content-Type: application/json
Content-Disposition: attachment; filename="macros-export-2026-05-22.json"
```

### `GET /api/export/pdf?from=&to=`
**Response:** stream de PDF con:
- Página 1: portada con nombre, rango fechas, totales
- Página 2: gráfica de calorías diarias (SVG embebido)
- Página 3: gráfica de macros (P/C/G como % del total)
- Páginas 4+: tabla de comidas (paginada)

**Headers:**
```
Content-Type: application/pdf
Content-Disposition: attachment; filename="macros-report-2026-05-22.pdf"
```

## Modificación crítica: `DELETE /api/account`

```ts
export async function DELETE() {
  const session = await auth();
  if (!session?.user?.id) return unauthorized();
  const userId = Number(session.user.id);

  // GDPR: exportar JSON antes de borrar
  const exportData = await buildJsonExport(userId);
  await sendAccountDeletionExport(
    session.user.email!,
    JSON.stringify(exportData, null, 2)
  );

  // Borrado en transacción (como hoy)
  await prisma.$transaction([
    prisma.meal.deleteMany({ where: { userId } }),
    prisma.goal.deleteMany({ where: { userId } }),
    prisma.food.deleteMany({ where: { userId } }),
    prisma.user.delete({ where: { id: userId } }),
  ]);

  return Response.json({ ok: true });
}
```

  it("includes all user data", async () => {
    const res = await GET(mockRequest());
    const data = await res.json();
    expect(data.user).toBeDefined();

    expect(data.goals).toBeDefined();

## Riesgos específicos

| Riesgo | Mitigación |
|---|---|
| `@react-pdf/renderer` puede no funcionar en Vercel Edge | Forzar Node runtime: `export const runtime = "nodejs"` |
| PDFs grandes (>1000 meals) pueden exceder timeout 10s | Paginar tabla o limitar a últimos 365 días por defecto |
| Email de export con JSON grande puede exceder límite Resend | Subir JSON a Vercel Blob y enviar link en email |
| Apple Health write-back queda pendiente | Documentar como "futuro con HU-08" |
