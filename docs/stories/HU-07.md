# HU-07: Micronutrientes inteligentes

> **Sprint:** 8 · **Etiqueta:** 🏗️ Cimiento · **Esfuerzo:** 10 días-persona · **Branch:** `feat/HU-07-micronutrients`

---

## Objetivo
Mostrar 3-5 micronutrientes priorizados por perfil del usuario, con alertas de déficit y vista completa expandible.

---

## Decisiones aplicadas
- **D1:** Fuente de datos = **USDA FoodData Central API** (gratuita, API key requerida)
- **Scope inicial:** 15 micronutrientes (no 84) — los más relevantes en LATAM:
  fibra, azúcar, sodio, potasio, calcio, hierro, vitamina C, vitamina D, vitamina B12, vitamina A, folato, magnesio, zinc, omega-3, omega-6

---

- ❌ Sin tabla de RDAs
- ❌ Sin perfilado de prioridades

## Cliente USDA FDC

### `lib/usda/client.ts`

```ts
const FDC_BASE = "https://api.nal.usda.gov/fdc/v1";

type FDCNutrient = {
  nutrientId: number;
  nutrientName: string;
  unitName: string;
  value: number;
};

type FDCFood = {
  fdcId: number;
  description: string;
  foodNutrients: FDCNutrient[];
  dataType: string;
};

// Mapeo de IDs de FDC a nuestros campos
const NUTRIENT_MAP: Record<number, keyof FoodMicros> = {
  1003: "p",          // Protein
  1004: "f",          // Total lipid (fat)
  1005: "c",          // Carbohydrate
  1008: "cal",        // Energy (kcal)
  1079: "fiber",      // Fiber
  2000: "sugar",      // Total sugars
  1093: "sodium",     // Sodium
  1092: "potassium",  // Potassium
  1087: "calcium",    // Calcium
  1089: "iron",       // Iron
  1162: "vitaminC",   // Vitamin C
  1114: "vitaminD",   // Vitamin D (D2 + D3)
  1178: "vitaminB12", // Vitamin B-12
  1106: "vitaminA",   // Vitamin A, RAE
  1190: "folate",     // Folate, DFE
  1090: "magnesium",  // Magnesium
  1095: "zinc",       // Zinc
  1404: "omega3",     // 18:3 (sum of omega-3s)
  1405: "omega6",     // 18:2 (sum of omega-6s)
};

export async function searchUSDA(query: string, pageSize = 10): Promise<FDCFood[]> {
  const url = `${FDC_BASE}/foods/search?api_key=${process.env.USDA_FDC_API_KEY}&query=${encodeURIComponent(query)}&pageSize=${pageSize}&dataType=Foundation,SR%20Legacy`;
  const res = await fetch(url, { next: { revalidate: 86400 } });
  if (!res.ok) return [];
  const data = await res.json();
  return data.foods ?? [];
}

export async function fetchFDC(fdcId: number): Promise<FDCFood | null> {
  const res = await fetch(`${FDC_BASE}/food/${fdcId}?api_key=${process.env.USDA_FDC_API_KEY}`);
  if (!res.ok) return null;
  return res.json();
}

export function extractMicros(food: FDCFood): Partial<FoodMicros> {
  const micros: Partial<FoodMicros> = {};
  for (const nutrient of food.foodNutrients) {
    const key = NUTRIENT_MAP[nutrient.nutrientId];
    if (key && nutrient.value != null) {
      micros[key] = nutrient.value;
    }
  }
  return micros;
}
```

## RDAs (`lib/micros/rda.ts`)

```ts
type Sex = "male" | "female";
type RDAEntry = { min: number; max?: number; unit: string };

/**
 * RDAs basadas en USDA Dietary Reference Intakes (DRI 2020-2025)
 * Para adultos 19-50 años; ajustes para mayores y otros perfiles.
 */
export function getRDA(nutrient: string, sex: Sex, age: number, fitnessGoal?: string): RDAEntry {
  const isMale = sex === "male";

  const RDAS: Record<string, () => RDAEntry> = {
    fiber:      () => ({ min: isMale ? 38 : 25, unit: "g" }),
    sodium:     () => ({ min: 1500, max: 2300, unit: "mg" }),
    potassium:  () => ({ min: 4700, unit: "mg" }),
    calcium:    () => ({ min: 1000, max: 2500, unit: "mg" }),
    iron:       () => ({ min: isMale ? 8 : 18, max: 45, unit: "mg" }),
    vitaminC:   () => ({ min: isMale ? 90 : 75, unit: "mg" }),
    vitaminD:   () => ({ min: 15, max: 100, unit: "µg" }),
    vitaminB12: () => ({ min: 2.4, unit: "µg" }),
    vitaminA:   () => ({ min: isMale ? 900 : 700, max: 3000, unit: "µg" }),
    folate:     () => ({ min: 400, max: 1000, unit: "µg" }),
    magnesium:  () => ({ min: isMale ? 420 : 320, unit: "mg" }),
    zinc:       () => ({ min: isMale ? 11 : 8, max: 40, unit: "mg" }),
    omega3:     () => ({ min: isMale ? 1.6 : 1.1, unit: "g" }),
    omega6:     () => ({ min: isMale ? 17 : 12, unit: "g" }),
    sugar:      () => ({ max: 50, unit: "g" }), // < 10% kcal
  };

  return RDAS[nutrient]?.() ?? { min: 0, unit: "" };
}
```

## Priorización (`lib/micros/prioritization.ts`)

```ts
type UserProfile = {
  sex: "male" | "female" | null;
  age: number | null;
  fitnessGoal: string | null;
};

const PRIORITY_RULES: Array<{
  predicate: (p: UserProfile) => boolean;
  micros: string[];
  reason: string;
}> = [
  {
    predicate: (p) => p.sex === "female" && (p.age ?? 0) >= 15 && (p.age ?? 0) <= 50,
    micros: ["iron", "folate", "calcium", "vitaminD"],
    reason: "Mujer en edad fértil",
  },
  {
    predicate: (p) => p.fitnessGoal === "gain",
    micros: ["zinc", "magnesium", "potassium", "iron"],
    reason: "Ganancia muscular",
  },
  {
    predicate: (p) => p.fitnessGoal === "lose",
    micros: ["fiber", "potassium", "magnesium", "vitaminD"],
    reason: "Pérdida de grasa — saciedad y energía",
  },
  {
    predicate: (p) => (p.age ?? 0) >= 50,
    micros: ["calcium", "vitaminD", "vitaminB12", "potassium"],
    reason: "Adulto mayor — densidad ósea y absorción",
  },
];

const DEFAULT_PRIORITY = ["fiber", "potassium", "vitaminD", "iron", "calcium"];

export function prioritizeMicros(profile: UserProfile): string[] {
  for (const rule of PRIORITY_RULES) {
    if (rule.predicate(profile)) {
      return rule.micros.slice(0, 5);
    }
  }
  return DEFAULT_PRIORITY.slice(0, 5);
}
```

## Riesgos específicos

| Riesgo | Mitigación |
|---|---|
| USDA FDC tiene rate limit (1000 req/hr) | Sync batch nocturno; cache 24h en `next.revalidate` |
| Alimentos LATAM (HU-12) sin USDA equivalente | Cargar manualmente desde TCA Colombia para regionales |
| Migración rompe Meal existentes (campos null) | Defaults null OK; queries existentes no leen micros |
| RDAs no aplican a condiciones especiales (diabetes, hipertensión) | Out of scope MVP; documentar disclaimer |
| Mujer < 15 o > 50 no entra en regla "edad fértil" | Validar; usar default |
